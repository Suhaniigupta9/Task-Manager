# Task Manager

A simple and interactive Task Manager application built using HTML, CSS, and Vanilla JavaScript to help users organize and manage their daily tasks efficiently.

## Features

- **Add Tasks:** Create new tasks easily.
- **Edit Tasks:** Update task details whenever needed.
- **Delete Tasks:** Remove tasks that are no longer required.
- **Priority Colors:** Organize tasks using color-coded priorities.
- **Task Completion:** Manage tasks based on their completion status.
- **Local Storage:** Save tasks in the browser so they remain available after refreshing the page.
- **Dynamic User Interface:** Update the interface through DOM manipulation and event handling.

## Technologies Used

- HTML5
- CSS3
- Vanilla JavaScript
- DOM Manipulation
- Browser Local Storage

## Getting Started

1. Clone or download this repository.
2. Open the project folder in Visual Studio Code.
3. Open `index.html` in your browser.
4. Start adding and managing your tasks.
